## 产品是什么

CrossWeb AI 是实际运行的对话式 AI 建站应用，目标是让用户通过自然语言**创建、预览，并在同一个项目上持续修改网站**。完整工作不止是模型返回页面代码，还涉及已有文件保护、工具权限、执行状态、失败恢复以及验证用户的新要求是否达成。

**最直接的作品证据是实际网站：** https://www.crosswebai.com/ 。请在网站中尝试创建一个测试网站，并在该项目上发出第二轮局部修改指令；公开仓库里的代码则用于独立复现具体工程设计，不需要把商业源码开源。

例如，可以使用一组有先后关系的测试需求（仅供浏览者自主尝试，不是已实测成功率声明）：

1. 创建一个设计咨询工作室网站，包含首页、关于页、主要服务和咨询入口。
2. 在同一项目中，只修改首页的 Hero 标题和颜色，保留关于页、全局导航和已有服务内容。
3. 对比修改前后页面，确认目标变更是否实施、已有功能是否保留，以及预览中是否存在异常。

如果网站要求登录、涉及额度或功能随版本变化，请以实时页面说明为准。

## 主要技术范围

实际私有产品涉及 Node.js 后端、OpenAI Agents SDK、工具调用、Neon PostgreSQL 项目/任务状态、E2B 隔离执行环境、构建与页面预览、结果审核、版本管理、Vercel 发布、运行追踪和用量控制。

**概念性用户旅程，不代表真实服务中的一条固定调用链：**

    用户提出建站 / 修改目标
                |
                v
    AI Agent 理解目标并调用受约束的工具
                |
                v
    隔离环境编辑项目 -> 构建与预览 -> 根据证据检查目标
                |                          |
                +------ 必要时修复 <-------+
                |
                v
    保存项目状态 / 版本 -> 用户继续修改或发布

跨越这些阶段，后端还需要处理并发、请求重放、Trace、成本预算及失败恢复。公开仓库不会伪装实现生产级 PostgreSQL 锁、完整 E2B 调度或所有部署细节。

## 工程决策：为什么不是简单的 AI 生成器

| 真实产品遇到的问题 | 设计关注点 | 此仓库可核实的简化示例 |
| --- | --- | --- |
| 多轮修改可能覆盖已有页面 | 新指令优先、保护未要求修改的文件 | [多页面修改及保留检查](../examples/showcase.mjs) |
| 模型会提供错误、模糊或越权的工具参数 | 运行时工具白名单和作用域约束 | [受限文件工具](../src/tools.mjs) 与回归测试 |
| 某一个页面通过检查不等于整个任务完成 | 外部目标契约，检查必须在最新修改后成立 | [完成证据逻辑](../src/agent.mjs) 与 [误判测试](../test/goal-verification.test.mjs) |
| 长任务可能出现重复请求和错误恢复 | 请求幂等、异常反馈后精准重试 | [请求协调](../src/run-coordinator.mjs) 与 [恢复案例](../examples/showcase.mjs) |
| 需要知道运行为什么慢、为何失败 | 分阶段 Trace、失败与 Token 分析 | [脱敏 Trace](../src/trace.mjs) |
| 修复一类故障可能引入另一类问题 | 受控 Eval、负例和证据不足判定 | [离线评测案例](../examples/eval-suite.mjs) |

## 公开工程案例与实际产品的边界

公开的 Agent Loop、工具模块、请求协调、Trace 和 Eval 均为**独立编写的教学规模工程复现**；用于展示处理问题的方法和测试证据。源码中的 HTML/CSS、模型输出和时延示意数据均为合成数据。它们不包含客户文件、真实项目源代码、商业提示词、认证信息、生产数据库结构、原始 Trace 或付费模型评测结果。

不能把示例自动化测试通过率当作真实模型的网站交付成功率，也不能用不完整的合成站点检查代替浏览器视觉体验评审。

## 招聘方技术核验路线

直接使用上方实际产品体验完整用户旅程，再用仓库中的零费用案例检查工程细节：

    npm test
    npm run demo
    npm run trace:demo
    npm run eval:demo

以上命令在 Node.js 20+ 环境下无需账号或密钥。测试输出和 GitHub Actions 状态验证的是**公开示例的行为**，不是私有产品的线上服务保证。
